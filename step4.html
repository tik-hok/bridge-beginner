第 4 步：叫牌，喊價決定合約

這一步的目標：看懂「2♥」「3NT」這種叫品的意思。先了解概念就好，不用背。

打牌之前，大家要先「喊價」，決定誰當王牌，以及要贏幾墩。

🗣️ 叫品 = 數字 + 花色

例如「2♥」的意思是：「紅心當王牌，我們會贏 6 + 2 = 8 墩」。

  • 數字是 1～7，要贏的墩數永遠是「6 + 數字」。
  • 花色可以選 ♣ ♦ ♥ ♠，或是 NT（無王，沒有王牌）。
🔢 叫品換算器：選選看，看看要贏幾墩。

📈 像拍賣一樣，越喊越高

後面喊的人要喊得比前面高：數字比較大，或數字一樣但花色等級比較高。

花色等級（由低到高）：♣ < ♦ < ♥ < ♠ < NT

不想喊的時候，可以說「Pass（不叫）」。有人叫牌後，連續 3 個人 Pass 就結束，最後的叫品就是合約。

得到合約的隊伍要努力贏到承諾的墩數；另一隊則要想辦法阻止他們。
